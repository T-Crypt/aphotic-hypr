<section class="page hero"><p class="eyebrow">Project status</p><h1>Shipped work, stated plainly.</h1><p class="lede">Aphotic is beta software. Public release notes distinguish delivered behavior from work tracked in issues.</p></section><section class="page prose"><h2>Stable and shipped</h2><p>The current public status is v2.0.7. The Quickshell desktop shell, wallpaper-driven themes, composable profiles and layers, modular plugin architecture, the Flow resource map, Desktop Pets, local-model inference mode, a self-checking installer and the Signal line interface are shipped.</p><h2>Experimental</h2><p>Newer surfaces and edge-case hardware or theme combinations can still have rough edges.</p><h2>In flight</h2><p>Work toward 2.1.0 happens in the open on <code>dev</code>. The remaining shell surfaces join the Signal design language. Agent harnesses and inference engines become data the shell reads. Plugins declare them in manifests, and drop-ins under <code>~/.config/aphotic/</code> override or add them. Flow v2 reworks the resource map.</p><h2>Planned</h2><p>Open work belongs in <a href="https://github.com/T-Crypt/aphotic-hypr/issues">GitHub Issues</a>. This site does not promote planned work as a present feature.</p><p><a href="{{ '/docs/release-notes/' | relative_url }}">Read release notes →</a></p></section>
